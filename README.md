## צפייה מקומית

אפשר פשוט ללחוץ פעמיים על `index.html`. לחלופין, מהתיקייה של האתר:

```bash
python -m http.server 8765
```

ואז לפתוח בדפדפן: http://localhost:8765

## עדכון טלפון, וואטסאפ, כתובת ושעות

פותחים את `site-config.js` בכל עורך טקסט (גם Notepad) וממלאים בין המירכאות:

```js
phone: "050-1234567",
whatsapp: "050-1234567",
address: { street: "רחוב המלאכה 5", city: "חולון", postalCode: "" },
hours: [
  { days: "ראשון – חמישי", time: "08:00 – 17:00", schema: "Su-Th 08:00-17:00" },
  { days: "שישי",          time: "08:00 – 13:00", schema: "Fr 08:00-13:00" },
  { days: "שבת",           time: "סגור" }
],
```

- כל עוד שדה ריק, הוא מוצג באתר כ"להשלמה" והכפתורים שתלויים בו לא פעילים.
- ברגע שממלאים טלפון, כל כפתורי "התקשרו" נפתחים. אותו דבר לגבי וואטסאפ וניווט.
- **שימו לב:** הנתונים המובנים לגוגל (AutoBodyShop) נמצאים ב-`index.html` בתגית `application/ld+json`, וגם הטלפון והכתובת מופיעים שם, בכותרת ובתיאור העמוד. אם משנים טלפון או כתובת, צריך לעדכן גם שם.
- מפת Google מוצגת אוטומטית אחרי שממלאים כתובת.
- `schema` בשעות הפעילות מיועד לגוגל (באנגלית: Su, Mo, Tu, We, Th, Fr, Sa).
- כרגע מוגדר `showPlaceholders: false`: שדות חסרים (שעות פעילות, פרטי "אודות") פשוט לא מוצגים. ברגע שממלאים אותם, הם מופיעים.

## הוספה והחלפה של תמונות בגלריה

1. שמים את התמונה בתיקייה `images/gallery/`. שם הקובץ באנגלית בלי רווחים, למשל `bumper-1.jpg`.
2. ב-`site-config.js`, תחת `gallery`, מוסיפים שורה:
   ```js
   { src: "images/gallery/bumper-1.jpg", title: "תיקון פגוש", alt: "פגוש קדמי אחרי תיקון וצבע", illustration: false },
   ```
3. `illustration: false` פירושו עבודה אמיתית, והתמונה תסומן "עבודה מהמוסך".
4. `wide: true` (לא חובה) הופך תמונה לרחבה, כפולה בגודלה.
5. כדי להסיר תמונת המחשה מוחקים את השורה שלה.

המלצות: רוחב 1600 פיקסלים, JPG או WEBP, עד כ-400KB לתמונה.
**לא להעלות תמונות שרואים בהן מספרי רישוי, פנים של לקוחות או מסמכים.**

### התמונה הראשית ותמונות השירותים
הן נמצאות ב-`index.html`. כדי להחליף, שמים קובץ (למשל `images/hero.jpg`) ומחליפים את הכתובת בתגית ה-`img` המתאימה (`src` ו-`srcset`). את השורה `<link rel="preload" ...>` בראש הקובץ מעדכנים לאותה כתובת.

## תמונות ההמחשה

כל התמונות שמורות בתיקיית האתר (`images/`) ולא תלויות בקישורים חיצוניים. מקורן ב-[Unsplash](https://unsplash.com/license), והרישיון של כל אחת נבדק: Unsplash License חינמי, לא Unsplash+. הרישיון מתיר שימוש מסחרי ולא מחייב קרדיט. רשימת הצלמים נמצאת ב-`images/CREDITS.md`. כל התמונות מסומנות באתר "תמונת המחשה", ויש הבהרה בגלריה שאינן עבודות של המוסך.

## קידום בגוגל (SEO)

מה כבר מוכן:
- כותרת ותיאור עמוד, מילות מפתח, Open Graph לשיתוף
- מבנה כותרות תקין (H1 אחד), טקסט חלופי לכל תמונה
- `sitemap.xml` ו-`robots.txt`
- נתונים מובנים AutoBodyShop, שנוצרים אוטומטית כשממלאים פרטים
- טעינה מהירה: תמונות בגודל מותאם, טעינה עצלה (lazy) ומעט קבצים

מה כדאי לעשות אחרי הפרסום:
1. לפתוח או לעדכן **פרופיל עסק בגוגל (Google Business Profile)**. זה הגורם המשמעותי ביותר בחיפוש מקומי.
2. לרשום את האתר ב-Google Search Console ולשלוח את ה-sitemap.
3. להחליף תמונות המחשה בתמונות אמיתיות.

> אין אפשרות להבטיח מקום ראשון בגוגל. הדירוג תלוי בגוגל, בתחרות ובפעילות העסק.
